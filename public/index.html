How it works

Four steps from private trade to copied trade.

  1. 01

    Trade without showing your hand

    Record each closed trade. The details are encrypted before they are stored. Only the totals leave the vault.

  2. 02

    Publish the scoreboard

    PnL, win rate, drawdown and trade count update for everyone. No pair, no prices, no thesis.

  3. 03

    Sell a window of access

    Set a price for 7 or 30 days. A follower pays and receives a viewing key. On testnet it is a grant on a NEAR contract.

  4. 04

    Unlock, then copy

    Key holders read the thesis and trades, then build NEAR Intents orders scaled to their own budget. You can revoke any holder early.

Trades go into the vault encrypted.

Access that ends

A key is a window that closes.

Every key has an expiry the moment it is sold. The trader can end it sooner. When the window closes, the private view locks again on the next request.

  • 7 or 30 day windows, priced by the trader
  • Buying again extends an active key
  • Revoke one holder without touching the rest

Under the hood

Built so the claims can be checked.

Encrypted at rest

Trades and tracked copies are sealed with AES-256-GCM, using a separate key per trader, before they reach disk.

A key is not a wallet

A viewing key is a read credential. It cannot sign, and it cannot move funds. The trader's manage rights are separate.

Grants on NEAR

On testnet the key is a grant on an access contract. The server asks the contract on every private request, so a revoke bites at once.

Wallet sign-in

NEP-413 message signing with a single-use nonce, plus a check that the signing key belongs to the account.

Copy through Intents

Holders get quote requests shaped for the NEAR Intents 1Click API, scaled to their budget. Nothing is submitted for them.

TEE, stated plainly

A real attestation quote appears only on a dstack host. Anywhere else the app says there is no TEE and that the operator can read trades.

FAQ

Straight answers.

Does this use real money?

Not by default. Dry-run mode simulates payments and needs no wallet. Testnet mode uses testnet NEAR only.

Can a key holder move my funds?

No. A viewing key only lets someone read your private strategy for a limited time.

What can the server operator see?

Without a TEE, the operator holds the encryption key and can read stored trades. The Security tab states this on every run.

Does a copy trade execute for me?

No. KeyView builds the orders and tracks the result. You submit them yourself.

Can a key be shared with someone else?

In dry-run mode the key is a bearer token, so it can be passed on. On testnet, access is tied to the holder's wallet account.
